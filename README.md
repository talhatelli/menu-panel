# Restaurant QR Menu & Management Panel

A QR code-based menu and order management system developed for modern restaurants. Customers can scan the QR codes on tables to access the menu and place orders, and all orders are instantly sent to the management panel.

## 🎯 System Features

### 1. QR Code System
- Unique QR codes for each table
- Easy menu access via QR code
- Table-based order tracking
- Contactless ordering

### 2. Menu Management
- Category-based product organization
- Add, edit, and delete products
- Price and stock management
- Add special notes and allergen information

### 3. Order Tracking System
- Real-time order notifications
- Table-based order viewing
- Order status updates
- Order history and reporting

### 4. Management Panel
- User-friendly interface
- Detailed reporting
- Staff management
- System settings

## 🛠 Technical Stack

- **Frontend:** Vue.js 3 + TypeScript
- **UI Framework:** Ant Design Vue
- **State Management:** Pinia
- **API Communication:** Axios
- **Build Tool:** Vite

## 🔧 Installation

1. Clone the repository
```bash
git clone https://github.com/talhatelli/menu-panel.git
```

2. Install dependencies
```bash
npm install
```

3. Set up environment variables
```env
VITE_API_URL=http://localhost:3000
VITE_BASE_URL=http://localhost:3000
VITE_BACKEND_URL=http://localhost:3000
```

4. Start the development server
```bash
npm run dev
```

## 👥 User Roles

1. **Admin**
   - Full system management
   - Staff management
   - Access to reports

2. **Waiter**
   - Order management
   - Update table status
   - View menu

3. **Kitchen**
   - View orders
   - Update order status
